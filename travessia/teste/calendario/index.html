📤 Levar para o Google Agenda

Baixe o arquivo .ics completo ou envie evento por evento para o Google Agenda, Apple Calendário ou Outlook.

🔗 Compartilhar calendário

Envie uma cópia por link, crie um link curto ou compartilhe um link ao vivo (somente leitura).

🖨️ Imprimir a lista

Gera uma versão limpa da lista de eventos com todos os detalhes abertos, pronta para PDF ou papel.

💾 Cópia de segurança (arquivo)

Salve uma cópia (.json) neste aparelho ou abra uma cópia salva anteriormente.

⚙️ Teste e limpeza (exemplo / apagar tudo)

O calendário fica salvo só neste navegador, neste aparelho (ou na sua conta gratuita se você entrar). Para levar para outro aparelho sem conta, salve uma cópia ou use o Google Agenda.
