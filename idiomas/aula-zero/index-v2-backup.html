1️⃣ Estrutura dos Moldes

A cópula (です) é o verbo "ser/estar" em japonês. É a base de tudo. Sem ela, não há frase em japonês. Aprenda a afirmar, negar e perguntar.

✓ です (Desu) — É / Sou

Estrutura:

[Item/Conceito] + です

Exemplos:

パスポートです
Pasupoto desu
É o passaporte
ブラジル人です
Burajiru jin desu
Sou brasileiro(a)

✗ ではありません (Dewa Arimasen) — Não é

Estrutura:

[Item/Conceito] + ではありません
Variações: じゃありません (jya arimasen) | じゃない (jya nai)

Exemplos:

観光客ではありません
Kankou kyaku dewa arimasen
Não sou turista (formal)
観光客じゃありません
Kankou kyaku jya arimasen
Não sou turista (coloquial)
日本人じゃない
Nihon jin jya nai
Não sou japonês(a) (informal)
パスポートじゃない
Pasupoto jya nai
Não é o passaporte

❓ ですか？ (Desu ka?) — É ...? (Pergunta)

Estrutura:

[Frase] + ですか？

Exemplos:

観光客ですか？
Kankou kyaku desu ka?
Você é turista?
ブラジル人ですか？
Burajiru jin desu ka?
Você é brasileiro(a)?
パスポートですか？
Pasupoto desu ka?
É o passaporte?

2️⃣ Sistema Verbal (~ます)

Os verbos em japonês mudam de forma para indicar tempo e polidez. O padrão ~ます (masu) é polido e formal. Aprenda as 4 formas básicas de cada verbo.

Todas as conjugações:

行きません

3️⃣ Os 5 Interrogativos Curinga

Estas 5 palavras são sua chave de ouro. Se você entender quando aparecem, saberá quando o fiscal ou atendente está te fazendo uma pergunta. Sempre seguidas de か？(ka?) no final.

何 (Nan) — O quê? / Qual?

Estrutura:

何 + ですか？

Exemplos:

何ですか？
Nan desu ka?
O que é?

どこ (Doko) — Onde?

Estrutura:

どこ + ですか？

Exemplos:

どこですか？
Doko desu ka?
Onde é?

誰 (Dare) — Quem?

Estrutura:

誰 + ですか？

Exemplos:

誰ですか？
Dare desu ka?
Quem é?

なんで (Nande) — Por quê?

Estrutura:

なんで + ですか？

Exemplos:

なんでですか？
Nande desu ka?
Por que?

いつ (Itsu) — Quando?

Estrutura:

いつ + ですか？

Exemplos:

いつですか？
Itsu desu ka?
Quando é?

4️⃣ As 6 Peças Curinga Essenciais

Estes padrões te salvam no aeroporto, no Japão e em qualquer situação. São de altíssima frequência. Decora bem!

1. ~は どこですか？ (Wa Doko Desu ka?) — Onde fica X?

A estrutura número 1 de sobrevivência. Use para encontrar lugar, serviço ou coisa.

Estrutura:

[Lugar/Serviço/Coisa] + は どこですか？

Exemplos:

トイレはどこですか？
Toire wa doko desu ka?
Onde fica o banheiro?
パスポートはどこですか？
Pasupoto wa doko desu ka?
Onde está o passaporte?

2. ~が あります / ありません (Ga Arimasu/Arimasen) — Existe / Não existe

Estrutura:

[Item] + が あります | + が ありません

Exemplos:

申告があります
Shinkoku ga arimasu
Tenho algo a declarar
フライトがあります
Furaito ga arimasu
Tenho um voo

3. ありがとうございます / すみません (Arigatou Gozaimasu / Sumimasen)

Sumimasen é o canivete suíço: serve para chamar atendente, pedir licença e pedir desculpas.

Exemplos:

すみません
Sumimasen
Com licença / Desculpa
ありがとうございます
Arigatou gozaimasu
Muito obrigado(a)

4. ~は いくらですか？ (Wa Ikura Desu ka?) — Quanto custa?

Estrutura:

[Item] + は いくらですか？

Exemplos:

いくらですか？
Ikura desu ka?
Quanto custa?

5. ~ても いいですか？ (Te Mo Ii Desu ka?) — Posso? / É permitido?

Estrutura:

いいですか？ (forma rápida)

Exemplos:

いいですか？
Ii desu ka?
Pode? / Tudo bem?

6. ~を (Wo/O) — Partícula do Objeto Direto

A partícula を (wo/o) marca o objeto direto. Essencial para pedir coisas.

Estrutura:

[Objeto] + を ください | + を お願いします

Exemplos:

水をください
Mizu wo kudasai
Me dê água, por favor
窓側をお願いします
Madogawa wo onegai shimasu
Janela, por favor
