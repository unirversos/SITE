Estrutura dos Moldes

🎧 Ouça a Aline explicar antes de praticar

A cópula (です) é o verbo "ser/estar" em japonês. É a base de tudo. Aprenda a afirmar, negar e perguntar.

✓ です (Desu) — É / Sou

⌄

Estrutura:

[Item/Conceito] + です
= X desu
Ex: [Seu nome] + です = Sou [seu nome]

Exemplos:

ブラジル人です
Burajiru jin desu
Sou brasileiro(a)
ほんとうです
Hontou desu
É verdade
Aline desu
[Seu nome] + desu
Sou Aline

✗ ではありません (Dewa Arimasen) — Não é / Não sou

⌄

Estrutura:

[Item/Conceito] + ではありません
Variações: じゃありません (jya arimasen) | じゃない (jya nai)
= X dewa arimasen / X jya arimasen / X jya nai
Ex: [Seu nome] + dewa arimasen = Não sou [seu nome]

Exemplos:

観光客ではありません
Kankou kyaku dewa arimasen
Não sou turista (formal)
日本人じゃありません
Nihon jin jya arimasen
Não sou japonês(a) (coloquial)
ほんとうじゃない
Hontou jya nai
Não é verdade (informal)
Aline dewa arimasen
[Seu nome] + dewa arimasen
Não sou Aline

❓ ですか？ (Desu ka?) — É ...? (Pergunta)

⌄

Estrutura:

[Frase] + ですか？
= X desu ka?
Ex: [Seu nome] + desu ka? = Você é [seu nome]?

Exemplos:

観光客ですか？
Kankou kyaku desu ka?
Você é turista?
ブラジル人ですか？
Burajiru jin desu ka?
Você é brasileiro(a)?
ほんとうですか？
Hontou desu ka?
É verdade? / Sério?
Aline desu ka？
[Seu nome] + desu ka?
Você é Aline?

Sistema Verbal (~ます)

Os verbos mudam de forma para indicar tempo e polidez. Cada verbo tem 4 conjugações: presente, negativo, passado e passado negativo.

行く (Iku) — Ir

⌄

Padrão:

[Base] + ます / ません / ました / ませんでした
Iku → Iki + masu / masen / mashita / masen deshita

Conjugações:

行きます
Ikimasu
Vou / Vou ir (presente)
行きません
Ikimasen
Não vou (negativo)
行きました
Ikimashita
Fui / Ia (passado)
行きませんでした
Ikimasen deshita
Não fui (passado negativo)

食べる (Taberu) — Comer

⌄

Padrão:

[Base] + ます / ません / ました / ませんでした
Taberu → Tabe + masu / masen / mashita / masen deshita

Conjugações:

Os 5 interrogativos curinga e as 6 peças essenciais que salvam sua vida no Japão.

5 Interrogativos Curinga

何 (Nan / Nani) — O quê?

⌄
何 (nan / nani) + ですか？
= Nan desu ka?
何ですか？
Nan desu ka?
O que é?

どこ (Doko) — Onde?

⌄
どこ (doko) + ですか？
= Doko desu ka?
どこですか？
Doko desu ka?
Onde é?

誰 (Dare) — Quem?

⌄
誰 (dare) + ですか？
= Dare desu ka?
誰ですか？
Dare desu ka?
Quem é?

なんで (Nande) — Por quê?

⌄
なんで (nande) + ですか？
= Nande desu ka?
なんでですか？
Nande desu ka?
Por que?

いつ (Itsu) — Quando?

⌄
いつ (itsu) + ですか？
= Itsu desu ka?
いつですか？
Itsu desu ka?
Quando é?

6 Peças Essenciais de Sobrevivência

1. Onde fica X?

⌄
[Lugar/Serviço/Coisa] + は どこですか？
= X wa doko desu ka?
トイレはどこですか？
Toire wa doko desu ka?
Onde fica o banheiro?
パスポートはどこですか？
Pasupoto wa doko desu ka?
Onde está o passaporte?

2. Existe / Tenho?

⌄
[Item] + が あります | + が ありません
= X ga arimasu / arimasen
アレルギーがあります
Arerugī ga arimasu
Tenho alergia
フライトがあります
Furaito ga arimasu
Tenho um voo

3. Obrigado / Desculpa

⌄
すみません
Sumimasen
Com licença / Desculpa
ありがとうございます
Arigatou gozaimasu
Muito obrigado(a)

4. Quanto custa?

⌄
[Item] + は いくらですか？
= X wa ikura desu ka?
いくらですか？
Ikura desu ka?
Quanto custa?

5. Posso?

⌄
いいですか？ (forma rápida)
= Ii desu ka?
いいですか？
Ii desu ka?
Pode? / Tudo bem?

6. Me dê X, por favor

⌄
[Objeto] + を ください | + を お願いします
= X wo kudasai / onegai shimasu
水をください
Mizu wo kudasai
Me dê água, por favor
窓側をお願いします
Madogawa wo onegai shimasu
Janela, por favor
